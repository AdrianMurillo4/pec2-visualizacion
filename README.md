# PEC 2 · Visualización de datos

Web interactiva con Circle Packing, Gantt Chart y Convex Hull, elaborada con D3.js.

## Datos y fuentes

- `circle_packing_gapminder_2007.csv`: 142 países del dataset Gapminder 2007. Fuente: https://github.com/plotly/datasets/blob/master/gapminderDataFiveYear.csv
- `iris_convex_hull.csv`: 150 observaciones del dataset Iris. Fuente: https://archive.ics.uci.edu/dataset/53/iris y https://github.com/mwaskom/seaborn-data/blob/master/iris.csv
- `gantt_proyecto_software.csv`: 10 tareas sintéticas de planificación; datos didácticos, no proceden de una empresa real.
- Visualización mediante D3.js v7: https://d3js.org/

## Uso de IA

Se ha utilizado ChatGPT (OpenAI) para apoyar la selección y transformación de datos, programación y explicación de las visualizaciones. Revisar los datos, la interpretación y la declaración de uso de IA según los requisitos de la asignatura. Cualquier vídeo requerido debe grabarlo y locutarlo el estudiante.

## Publicación

En **Settings → Pages → Build and deployment → Source**, seleccionar **GitHub Actions**. El flujo `.github/workflows/pages.yml` publica el sitio automáticamente con cada cambio en `main`.
